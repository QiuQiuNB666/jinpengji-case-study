# 锦鹏记 · 经营调研报告

深圳罗湖粤港新天地美食广场潮汕菜档口的经营调研与打法建议。

报告点名了真实门店的位置与人均，并对经营状况作了判断。分析基于公开信息与通用行业资料，结论中的「可能在亏损」等表述是条件推演，不是对该店实际经营数据的断言。

## 内容

[锦鹏记调研报告.md](锦鹏记调研报告.md)，约 3.5 万字，由七路并行调研加两轮评审合成。

两个已给出的结论：

| 问题 | 结论 |
|---|---|
| 外卖 | 不做，也不做到店自取。启动条件见报告第 4 节 |
| 带货回港 | 做，但先用手写黑板试水，不要先买包材 |

优先级最高的两件事与营销无关：

1. 鲜粿条按日订货、当日未用完报废、建进货台账。湿米粉保质期普遍 24 小时，超期后感官正常但可能产生米酵菌酸，无特效解毒药。
2. 先算保本点再花钱引流。每单利润为负时，引流是把亏损乘上更多单。

## 尚未取得的信息

报告第 8 节列了四项「门禁级」信息，翻合同看证照就能答，它们决定过半动作是否合法可做：

- 收银主体是谁，顾客的钱先进谁的账
- 食品经营许可证的持证主体是门店还是商场运营公司
- 经营范围是否含热食类食品制售与散装食品销售
- 外卖、团购、自取流水是否计入商场扣点基数

凡依赖未取得信息的结论，报告都写成了 if-then 两个分支。

## 数据口径

报告内标注「待核实」的项目在核实前不得作为投入决策依据。平台与厂商自述数据已标注来源性质，不作 KPI 目标值。
